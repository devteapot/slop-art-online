# Shared harness: the world guard's disk floor

Validated on the dev-box on branch `vol-interval`, from `origin/main` `e1f380909`, before its commit. Tooling and documentation only (`living/tools/world_guard.py`, `verify_lease_selftest.py`, docs/TRIAL_DISK.md, docs/BATTLE_VIEWERS.md, this skill's SKILL.md). Server: a private `clockworklabs/spacetime:v2.14.1` container, `vi-stdb` on `127.0.0.1:3341` with its own `/wasm` mount, started in its own systemd scope and removed with its volume afterwards. No mind service, no Neo4j.

## Design

The orphan guard every launch arms (`world_guard.arm`) also reads the host's free space with `statvfs` every 5 s (`SLOP_GUARD_DISK_PATH`, default the home directory) and, under `SLOP_GUARD_FREE_FLOOR_GB` (15 by default, `0` off, read at arm), pauses its world at once through the same calls as an orphan pause: the singleton `world` SQL read, the admin `set_paused` reducer, a read-back. It adds no reducers, tables or subscriptions; the reading itself makes no server call. It writes `world-guard-disk.json` in the run directory, keeps guarding, pauses again a world unpaused while the disk is low, and never unpauses. Routes: [SpacetimeDB database HTTP API](https://spacetimedb.com/docs/http/database/), as already used by the guard (docs/TRIAL_DISK.md).

## Live check

- `verify.py launch --run vi-floor --seed hamlet` with `SLOP_GUARD_FREE_FLOOR_GB=100000` (66 GB free): the guard armed at 16:48:08 +0100, logged `PAUSING: free space 66.1 GB under the floor of 100000 GB` and `PAUSED AND VERIFIED by SQL (disk floor)` at 16:48:09; SQL read `paused: true`; `world-guard-disk.json` written.
- `verify.py call --run vi-floor --as-admin set_paused '[false]'` (200, SQL `paused: false`): within the next reading the guard logged `the world was unpaused while free space is 65.2 GB: PAUSED AGAIN, verified by SQL`; SQL read `paused: true`.
- `verify.py cleanup --run vi-floor`: deleted, the name no longer resolves; the guard process exited with its lease.
- Evidence: `.local/living/verify/vi-floor/` and `.local/vi-launch.log`, archived in `~/archive/worktree-evidence-20261121/vol-interval-vi-floor.tar.gz`.
