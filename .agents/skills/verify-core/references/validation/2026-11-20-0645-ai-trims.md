## What changed

- **Trims, each exact:** the scene's candidates ordered only as far as read (`perception::Sensing`, a heap on `common::nearest_key`); a move check's and a move start's context built from the fields their plans read (`act::target_facts_reading`, `facts_at`, `Reads::of_start`); a needs recompute given the `rates` law's fields and the genes its answer is finished with (`act::rates_facts`); one activity read per graph leaf (`act::begin_with`) and one at an evaluation's end (`town::settle_with`, `perceive::slept_with`, the character read only on waking); one character read in the nearest pick.
- **A determinism fix (not exact with main's arbitrary order):** `common::due_bystander_wakes` delivers held-back bystander wakes in id order. Main's order was a `HashMap`'s, whose keys on wasm32 come from memory addresses, so it differed between builds: two builds differing only in profiling spans evaluated woken residents in another order from the 76th tick of the battle.
- **Diagnostic laws, off in play:** `det_clock` (the tick's clock, draws and housekeeping follow the tick count; each tick logs a hash of every table) and `det_stop` (pause at a tick). `living/authority/src/det.rs`; `living/tools/det_compare.py`. The compile-time control `LIVING_DET_PERTURB`.
