# Gaze in a mind's scene

`{"do":"gaze","band":"far"}` selects a sight band without replacing a graph. The same attention setter handles this act and `human_gaze`. The Cullet [gaze scene](../../verify-player/features/gaze.md) checks the reducer, a checked batch, graph revision and a pending scene. Run `verify_minds.py --run minds-gaze-<id> --case gaze` to drive a real mind with the loopback fake endpoint and inspect the next prompt.
