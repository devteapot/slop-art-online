# Gaze client validation

On the Cullet scratch run `player-gaze-052420`, two WebSocket SDK clients used
independent player identities. Each subscribed to `my_senses_v_2` and saw
exactly its own row, one Far and one Near. The non-owner SDK refused both
`attention` and `applied_gaze`. SQL also confirmed that the anonymous view
returned zero rows.

See the four SDK assertions and the SQL checks in
`.local/living/verify/player-gaze-052420/gaze-proof.jsonl`. The new view is
additive under the pinned SpacetimeDB 2.14.1 migration planner. The legacy
`my_senses` schema stays compatible. [Migration decision](../../../../../docs/CAMERA.md#spacetimedb-2141-delivery-decision).
