# Gaze projection and privacy

`attention` and `applied_gaze` are private. `my_senses_v_2` is empty with gaze off. In enabled worlds it delivers the owner's last scheduled sweep band and field. The original `my_senses` keeps its original row shape.

Run the [Cullet gaze scene](../../verify-player/features/gaze.md) with `GAZE_SDK_PROBE` set to the built probe. It subscribes as two distinct players and tries both private tables over WebSocket.
