# The effective cover policy and private geometry

The public singleton is `cover_law`. A player cannot read the private `cover_ground` bands, nor `cover_derivation` and `cover_timer` (a derivation after a switch-on, `cover-genesis`), nor `cover_source` (a land's ground source, kept at creation with cover off so a switch-on samples it in short steps, `cover-stall`); all in the private-table inventory. `cover_law` reads on only when the land's cover geometry is complete. Cover changes the scoped seen rows at the authority.
