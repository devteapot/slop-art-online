# hair-mirror validation

Branch `hair-mirror`, from `origin/main` `7f73c04c8`. The binaries under test were built from the branch's working tree before commit, the same code as the commit. Cause, fix and every number: [docs/char-port-2/hair-mirror/README.md](../../../../../docs/char-port-2/hair-mirror/README.md).

**What changed in the client:** a dev switch of the asset view, `LIVING_GAME_VIEW_CLIP=bind` (`view.rs`, `lookdev.rs`), and a unit test. The tooling changed too: `image_spread.py --pose`, and the mirror-check tools. No authority, rules, table, reducer, view or subscription changed.

## Setup

- **Hardware and server:** Apple M4 Pro, Metal, Bevy 0.20.1. SpacetimeDB 2.14.1 at `http://127.0.0.1:3300`.
- **Builds:** release builds through `build-slot` (`BUILD_SLOTS=1`), with `CARGO_TARGET_DIR=$HOME/.cache/hair-mirror-target`.
  - **Main:** main's binary, built first and copied (`.local/s6/living-game-main`).
  - **The branch:** `.local/s6/living-game-bind`.
- **Assets:** the pinned render set `79072c65d37f`, with `lookdev` copied (APFS clone) into the worktree so the mirror builds could be installed. They were removed afterwards, and the copy then compared equal to the set (`diff -rq`).
- **Scratch worlds:** `verify-ui-hm-i` (island) and `verify-ui-hm-c` (Cullet), each deleted through `verify.py cleanup` (both 404 afterwards).
- **No reference, play or walk world was used, and no model was called.**
