# Hand-made hair validation

Branch `handmade-hair`, tested at `88b9553c8`. This pass covers the character rendering change in [the asset contract](../../../../../docs/HANDMADE_HAIR.md) and the verify-ui features that exercise character drawing. The change is client-side.

## Setup

- Apple M4 Pro, native headless Bevy 0.20.1 on Metal. The release client and island authority were built in `$HOME/.cache/handmade-hair-target` through `build-slot` with `BUILD_SLOTS=1`.
- The harness launched `verify-ui-handmade-1119` on a dedicated SpacetimeDB 2.14.1 container at `127.0.0.1:55329`. It used the island seed and scoped perception. The doctor's check ran before each scenario. No mind service or model calls ran.
- Generated character and environment assets came from the worktree's existing assets and asset links. The launch log's dirty marker includes these untracked links. There were no tracked changes under `living/`.
- Scene setup is recorded in each drive's `scene.json`. The LOD and seat fixtures place characters and set daylight through the authority's admin calls. Seat also sets the weather, sets residents' rest and wander behaviour, and places them again for the rise. Hair scripts a resident's line with `mind_say` so the camera frames the speaker.
