# Sit-f-select validation

Follows [2026-11-19-1522-sit-hips](2026-11-19-1522-sit-hips.md). Branch `sit-f-select`, from `origin/main` `8851982d2`. The binary was built from the branch's working tree, which differs from the commit only by a doc comment in `gait.rs`.

This is a client-only change: no authority, table, reducer, view or subscription change. A generated adult wearing `trousers-f` and `boots-f` plays the female ground-sit variants (`sit_ground_down_f`, `sit_ground_f`, `stand_up_ground_f`) in place of the logical ground clips. Design and numbers: `docs/seat-contact/sit-f-select.md`. Spec: `docs/seat-contact/female-ground-bake/README.md`.

## Found, not fixed

Taking the camera far (`notches:-30`) makes a seated resident start `stand_up_ground` and be set back to `sit_ground_down` 0.03–0.19 s later. It happened in all three seat runs, with variants and originals. The interrupted rise crossfades to the descent's standing start in 0.09 s (peak 9–12.5 m/s at the feet). It is the far/near path's behaviour, not the clips'.
