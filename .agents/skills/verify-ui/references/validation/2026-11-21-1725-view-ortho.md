# view-ortho validation

Branch `view-ortho`, from `origin/main` `a76dfc3f3` with `origin/hair-mirror` merged (it adds `LIVING_GAME_VIEW_CLIP=bind`). The binaries under test were built from the branch's working tree before commit, the same code as the commit. Design, the known answer and S7's gap: [docs/char-port-2/measure-view/README.md](../../../../../docs/char-port-2/measure-view/README.md).

**What changed in the client:**
- **The measuring view** (`view.rs`): `LIVING_GAME_VIEW_ORTHO`, `_ORTHO_M` and `_ORTHO_Y`, with per-photograph `.ortho.json` sidecars.
- **The finishing pass:** it reads an orthographic depth (`post.rs`, `edges.wesl` `dist`).
- **The far models:** `lookdev::far_models` counts an orthographic camera's pixels per metre.
- **Tests and tools:** four unit tests and an extended far-model test, plus the selftest tools `ortho_shape.py` and `ortho_selftest.py`.

No authority, rules, table, reducer, view or subscription changed.

**The maintenance pass:** `maintain-verification-skill`, scoped to the new surface only (no full audit).
- **What it added:** [features/measure-view.md](../../features/measure-view.md), its rows in [features/README.md](../../features/README.md) (feature and source tables), and a pointer from [hair.md](../../features/hair.md)'s asset-view paragraph.
- **The index:** every other feature file still has its row.

## Setup

- **Hardware and server:** Apple M4 Pro, Metal, Bevy 0.20.1. SpacetimeDB 2.14.1 at `http://127.0.0.1:3300`.
- **Builds:** release builds through `build-slot` (`BUILD_SLOTS=1`).
  - **The branch:** `CARGO_TARGET_DIR=$HOME/.cache/view-ortho-target`, an APFS clone of hair-mirror's target.
  - **Main:** built from a detached scratch worktree of `a76dfc3f3` and copied out. Its target was deleted afterwards.
  - **The disk guard:** `BUILD_SLOT_MIN_FREE_GB=8`, because the laptop had 9–24 GB free; the builds were incremental on clones.
- **Assets:** the pinned render set `a7c606d204bb`, its `lookdev` cloned (APFS) into scratch copies and linked into both worktrees.
  - **One pristine copy:** used for pixel identity and verify-ui.
  - **One copy with the ear-ID types and `bob_none`:** used for `face_rows.py`.
  - Environment kits, `textures` and `looks.json` were linked from the set, and `view` from the main checkout (read only).
- **The scratch world:** `verify-ui-vo-i` (island), deleted through `verify.py cleanup` (404 afterwards).
- **No reference, play or walk world was used, and no model was called.**
