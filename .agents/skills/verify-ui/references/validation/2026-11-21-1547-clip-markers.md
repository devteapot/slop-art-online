# clip-markers validation

Branch `clip-markers`, from `origin/main` `7f73c04c8`. Cause, fix and every number: [docs/CLIP_MARKERS.md](../../../../../docs/CLIP_MARKERS.md). It follows the red-on-main entry `look-walk` (92/8 on dev-box's set `79072c65d37f`, owner laptop).

The branch changes the clip bake and its packaging: `animate.py`'s `clean_contacts`, `gen_anim.sh` (`KIMODO_DIR`), `gen_person.sh` (`marker_check` on `own-clips`), `bundle.py --with-clips` (packs `own-clips.clips.json`) and `render_set.py` (`build` refuses a set without a sidecar or with failing markers; `check` warns). There is no client, authority, rules, table, reducer, view or subscription change, so the client under test is main's code.

Each arm replaced only `lookdev` with a folder of links to the set's `lookdev` whose `anim/` differed.
