# Cover sight in the game client

The first Cullet and island modules and the release game client were built at `c952cd9e`. The work branch was fast-forwarded to `f75a4b7d`, whose only change is the switch-on cost budget in [Cover sight](../../../../../docs/COVER_SIGHT.md). The runs used a private Cargo target and SpacetimeDB 2.14.1 on localhost. The game read generated assets through links to the play9 asset directory.

The Cullet player read the six-field `cover_law` singleton with both switches false at genesis and both true after the two admin calls. The scenes used admin placement and held the same resident still. Each camera stop records the law, exact body positions and authority perception, plus the client's draw, label and pick state and the corresponding Shade texture. The hidden contacts were tested with sheathed and drawn taps. The in-game wheel drove the branch's actual north-up top-down curve, which uses 65°, 58° and 48° at 19, 12 and 8 m. The requested fixed-58° and LoL presets are unavailable in this checkout.

The native `sightfield::tests::shade_matches_shared_authority_cover` test passed. Its output is in `.local/living/verify/ui-cover-1119/native-shade.log`. An initial UI attempt was invalidated by the verification orphan guard pausing both worlds after their standalone launch commands exited. The paused attempt is under `ui-paused/`. Both scratch worlds were resumed and checked with doctor before live captures.

The live Cullet client streams its land and authored Hanger trees through `island.rs` and `envs::cutaway`. The canopy stills and logs exercise that path. The procedural tree renderer in `world.rs` and its `fade_trees` system remain outside the live evidence.
