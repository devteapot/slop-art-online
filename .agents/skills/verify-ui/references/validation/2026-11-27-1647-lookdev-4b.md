# lookdev-4b: sharpened upscale, continuous edge width, Gaussian shadows on every tier

**Branch** `lookdev-4b`, from `origin/main` `f534c4185` (look-dev step 4). Laptop, shared SpacetimeDB `2.14.1` at `127.0.0.1:3300`. The release client was built in `$HOME/.cache/lookdev4-target` through `build-slot` (`BUILD_SLOTS=1`), with the pinned render set `~/slop-assets/a7c606d204bb` linked into the checkout's assets.

**What changed.** The game client, `check.py` and the feature map only. `living/scripts`, `living/authority`, `living/rules` and `living/bindings` are untouched. The details are in [features/graphics.md](../../features/graphics.md).
- `graphics.rs` and `upscale.wesl`: a scaled 3D picture is now composited through a fullscreen `MaterialNode<UpscaleMaterial>`: Catmull-Rom resampling plus contrast-adaptive sharpening, at sharpness 0.0, AMD's lightest. It replaces the bilinear `ImageNode`. `LIVING_GAME_PERF=upscale=bilinear` and `sharpen=S` exist for A/B runs. At 100% nothing changes: there is no target, camera or pass.
- `edges.wesl`: the line width is no longer rounded to whole pixels. The ring of neighbours is `edge_ring`, and a fractional width mixes the outer ring in by the fraction. A whole width takes the single ring as before.
- `Quality`: Medium and Low filter shadows `Gaussian`, as High does. `Hardware2x2` remains only as a `LIVING_GAME_PERF=shadowfilter=hw` override.
- `main.rs`: `LIVING_GAME_FULLSCREEN=1` opens a windowed run borderless on the primary display, for live 2x look-dev captures.
- The dump gains `extra.upscale` (`{method, sharpness}`, or null at 100%) and `extra.shadow_filter`. `check.py` gains the `graphics` scenario.
