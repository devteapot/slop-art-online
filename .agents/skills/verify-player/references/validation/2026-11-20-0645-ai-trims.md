# ai-trims: player combat through the trimmed move check and start (verify-player)

Branch `ai-trims` (Spark), final 1eac83d0 (docs/COMBAT_PHASE.md, "Step 3 results"). The scene gate's `combat` case (`combat.py --scene all`, an island world) on the private server `slop-aitrims-gate-20261120` (127.0.0.1:3521), the player identity over HTTP.

**Change that reaches players.** `use_skill` runs `act::begin` like a graph leaf: a move's check before it starts and its start (`perform`) now build only the fields their check and windup read (`check_ctx_plan`, on as shipped; `check_ctx_check` compares the whole context). A player's identical request gets the identical outcome: the same rules, and the same answer by construction (an unread field cannot change it), proven for AI moves tick by tick by `det_compare.py` and by `check_ctx_check` over a 500 s battle (none differed).

**Result:** `combat` passed, 54/54 checks over 17 scenes (block, bolt, bow, breath, committed, death, dodge, early_dodge, fast_lane, heal, jump, kill, onlooker, refusals, shot, strike, wolves). Evidence: `.local/living/verify/gate-1120065624-cd9055-a-player/combat.json`.
