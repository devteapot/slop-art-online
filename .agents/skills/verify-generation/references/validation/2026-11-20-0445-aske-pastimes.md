# aske-pastimes: aske-coast and its variants recompiled with `sheet.pastimes`

- **Branch** `aske-pastimes` from main `12be6122` (cover-genesis); server: a scratch 2.14.1 container `aps-stdb` (local). Run `generation-aps-20261120-054236` (`--feature worlds --seeds aske-coast,aske-coast-crypercept,aske-coast-dynamic,aske-coast-yieldnorm`), evidence `.local/living/verify/generation-aps-20261120-054236-*` (archived to `~/archive/worktree-evidence-20261120/aske-pastimes-local.tar.gz`).
- **Cause:** `living/seeds/aske-coast.json` predated `efcd489a8`, which taught `author_world.py` the residents' `sheet.pastimes`; the three derived seeds (`-crypercept`, `-dynamic`, `-yieldnorm`, the base plus their own `rules`) carried the same residents. verify-generation flagged aske-coast's cached compile as not byte-equal (72 differences).

Each seed's diff is exactly 72 added `sheet.pastimes` (60 town and 12 village residents). `seed_fresh.py` gains a whole-seed `compile` check (through `author_world.py --seed-out`) and a `derived` check; on main's files both flag all four seeds, on the branch all are fresh.
- **Result:** all four children pass all 291 checks.
