# Batch 023: one useful paid prototype in a controlled wording comparison

Four fresh eighteen-minute worlds completed: two with the current controller wording and two with an additional generic invitation to reconsider current motives and activity. One treatment world produced an autonomous, paid and successful finite-buffer prototype. The exact source also matched an independent reference on 104 observer-only replay cases within its physical input domain. No actor completed independent practice, ordinary technique use or executable-code transfer. The author retrieved and inspected the code, but the original prototype report and code remained unassessed for run authorization at cutoff.

All four standard research, infrastructure, physical-copy, food, engine, scope and base audits pass. All sixteen actors survived; baseline `current-b` Cato suffered power-depletion damage, repaired his own obstructing behavior and finished at health 36. The other fifteen finished at 100. The observed prototype is a concrete success in one run, not proof that the additional wording reliably causes invention.

The four variants share identical invention-scenario bytes, initial personalities, model configuration, authority module and client. Both conditions include the same corrections to source-ID and declaration-syntax documentation. The baseline freezes `research-m6-8-contract`; treatment freezes `research-m6-9-self-direction`. The only behavioral source difference is one shared generic guidance string added to both built-in and external prompts. It invites the person to consider what is worth doing given current motives and evidence, including continuing, reconsidering a goal, choosing another activity or doing nothing. It does not mention research, code, teaching or a desired outcome. Both conditions retain the existing instruction against rewriting a useful habit merely because a model call occurred.

All responsibilities use Luna medium, with fifteen seconds after each serial completion and no call cap. The same low-pressure invention seed supplies unresolved hypothetical storage questions, survival habits and a local terminal, without a candidate program or answer. No participant action, prototype source, replay case or controller revision was injected during a live run.

The first launch, [023-research-self-direction](../output/batches/023-research-self-direction/), failed when the first variant could not bind occupied port 18995. It has only the manifest, plan, coordinator state and traceback, with no pilot, world or model journal. The successful retry is preserved separately; the failed launch is not counted as a scientific repeat.

## The authored finite-buffer program and its remaining gate

In self-direction-B, Ari's behavior observation at 610.089 seconds contains his assessed own forecast and permission to author. His actual proposal supplies the source and advance prediction; policy 35955 is accepted, then prototype job 6 is submitted in 35965 at 642.074 seconds. Completion 36129 at 645.306 seconds records three paid quanta and a matching result.

The exact program artifact hash, covering source, interface and contracts, is `657953dda7a9fd07628713b297cd5bdf4843bf8b25e23acdefae17a6a364bf96`. Its input contract is `[initial_stock, capacity, inflow_1, demand_1, ...]`; it adds each interval's inflow, caps storage, serves demand from available stock and accumulates unmet demand. It returns total served, total shortfall and final stock. The paid input `[8,12,9,2,1,10,7,2,0,8]` produces the submitted advance prediction `[20,2,0]`. The branches handle both overflow and temporary shortage; this is a substantive algorithm rather than a constant answer, identity operation or rescaling of the built-in scalar forecast.

The prototype consumes six electricity and three water through ordinary terminal quanta. Its report and portable program are separate records. Ari retrieves both in 38644 and 38646 at 722.651 seconds, and explicitly inspects source, including event 41690 at 799.509 seconds. By the final snapshot the original prototype report and program still lack the interpretations required for ordinary execution. There are no accepted practice or run submissions. Final exact-source availability is Ari's living personal copy plus the terminal copy; it has not reached another person or archive.

Ari's learning observation at 759.363 seconds actually contains the prototype report source, but its response is malformed. His learning observation at 835.686 seconds is also malformed and targets a waiting result rather than source assessment. These distinguish delivered evidence, generated output and accepted learning.

A later learning observation at 1004.789 seconds does explain the inspected algorithm using source 48723. Authority accepts reflection 50179 at 1016.865 seconds and creates derived assertion 50180. However, frozen `.2` associates an original holding assessment only with `knowledge_report` evidence. The `program_inspected` source therefore supports an accepted insight while leaving the executable holding's `interpreted_source` null. This is a demonstrated inspection-to-holding association limitation, separate from malformed responses and unavailable permissions.

Ari then voluntarily rereads the still-unassessed prototype report: action 51501 produces source 51502 at 1048.548 seconds. No subsequent learning call occurs before cutoff. [The full causal review](../output/batches/023-research-self-direction-retry/research-causal-findings.md) and [prototype chain](../output/batches/023-research-self-direction-retry/research-prototype-chain.json) retain all exact requests, receipts, inspections and final authorization state. An accepted derived algorithm assertion does not retroactively perform the missing report assessment or enable ordinary use.

[Observer-only replay](../output/batches/023-research-self-direction-retry/self-direction-b/observer-replay/summary.json) runs the exact retained source through the same bounded Rust kernel, without paying world work or creating character evidence. It matches an independent Python reference on 104 cases: the paid example, the other seeded schedule, empty-interval and zero-capacity boundaries, and 100 generated cases with random seed 23. For Cato's other schedule the output is `[14,2,1]`.

That replay domain requires nonnegative complete interval pairs, at least initial stock and capacity, and initial stock no greater than capacity. Outside it, an empty array errors, an unpaired trailing value is ignored, and a negative flow can yield negative served demand. The source does not validate the broader input domain. The 104 replay cases support bounded semantic usefulness; they are not 104 autonomous experiments, another person's paid practice or proof of broad robustness.
