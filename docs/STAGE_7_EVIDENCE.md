# Stage 7: scoped and universal physical laws

The [bounded Stage 7 implementation milestone is accepted](#acceptance-decision-bounded-stage-7-implementation-milestone). Scoped laws, paid personal capability development, installer-independent persistence and the declared faction-scale integration now have evidence. Autonomous law invention and universal ascension remain unproven, as does the stronger Stage 6 useful-code peer-learning chain. Stage 7 experiments import no earlier source, people, numerical answers or proof.

## Capability, scope and physical work

The same participant interface serves human and AI actors. Initial territorial grants belong to explicitly seeded people and regions; titles, councils and organizations confer no automatic power. Initial local grant holders may author local laws. Ordinary numerical research competence offers another authorship route; communicated law code followed by personal interpretation and paid practice offers an independent route toward installation. Under the initial authorization law, universal installation requires the actor's own successful, interpreted experiment for the exact candidate, universal scope and current binding. These gameplay authorization hooks can themselves be changed by a valid universal edit. A territorial hook cannot grant universal authority.

Law source defines up to eight permitted one-argument Rhai hooks, within the existing bounded interpreter and an 8,192-byte source limit. Law experiment requests supply one to sixteen private cases, explicit inputs and predictions. Compilation or ownership errors reject before work; running errors and wrong predictions retain actual paid experiment outcomes. Terminal work uses the same queue, electricity, cooling, wear and elapsed time as numerical research. Code and private experiment cases are separate physical records. Teaching code does not copy private proof or its author's practical competence.

Universal hooks have precedence over regional hooks; regions order by priority, then smaller area, then lexical ID. Only authored hooks replace weaker ones. Installation checks the expected revision and binding before staging for a subsequent update; activation rechecks the effective binding, which includes active revisions. Stationary invocations retain their formula binding, movement rebinds after crossing, and current authorization applies to committed effects at relevant locations. Invalid hook results are quarantined with fallback; valid harmful rules remain lawful outcomes. Installed source and active revisions persist independently of the author's life or office.

Personal code inspection, knowledge interpretation, paid practice and authority are separate states. Default catalogs omit source bodies. Explicit held-code inspection supports assessment of the exact current holding; installed-source inspection reveals an accessible rule without acquiring a portable record or personal experimental proof. Retained owner audit history cannot restore a lost personal code copy.
