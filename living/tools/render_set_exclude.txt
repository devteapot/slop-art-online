# Files in living/tools/{blender,characters,textures} that only check, measure or photograph:
# the render asset set's generator hash leaves them out (living/tools/render_set.py; docs/TOOLING.md,
# "Building the render asset set"). One path a line, relative to living/tools/, no globs: a new tool
# stays a generator input until it is read and listed here. Reviewed 2026-11-21 (render-set-exclude):
# none of these is imported by a file that is not listed (render_set.py refuses the list otherwise),
# none writes a generated asset, and a check that a generator runs (gen_types.sh's brow_check,
# bundle.py's checks) can stop a build but not change its output. Kept as inputs although they
# check or measure in part: eye_colours.py (compose.py imports it), shade_mean.py and
# look_lines.py (they also write files), pictures.py (its check is part of the bundle step),
# calibrate.py and composed_audit.py (ink_field.py, which writes ink maps, imports calibrate.py).
# Changing this file changes the hash: a pinned set reads stale until it is re-packed.
